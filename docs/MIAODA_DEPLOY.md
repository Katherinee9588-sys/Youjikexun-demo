# 秒哒（miaoda.cn）部署说明

> 现状与限制：秒哒是百度的**零代码自然语言 / 拖拽式应用搭建平台**，无 CLI / SDK / 代码导入通道（docs.miaoda.cn 无开发者文档）。秒哒命题要求「在秒哒平台上开发并发布到应用广场」获取 `xxxxx.appmiaoda.com` 链接。因此**本地 FastAPI + React 代码无法直接部署到秒哒**，必须在秒哒平台用自然语言重建一个等价演示应用。下面是一份可直接粘贴到秒哒对话框的搭建指令，产出后由你在平台点「发布」即可拿到公开链接。

## 可直接粘贴的自然语言搭建指令（主提示词）

把下面整段一次性粘贴进秒哒的新建应用对话框：

> 帮我做一个移动端优先的健康记录 App，名字叫「有迹可循」，面向围绝经期女性，用一句话记录每天身体变化。所有数据用演示用合成数据，不是真实用户数据。底部三个 Tab：首页、今日记录、趋势。整体风格温暖、克制、留白多，主色低饱和的暖灰与豆沙绿，圆角卡片，不要用医疗蓝。
>
> 【首页 Tab】顶部一行小字欢迎语「今天，你想记录什么」，下面一句副文案「想到哪里说到哪里，一句话也是有效记录」。中间一个大圆形录音按钮，长按开始录音、松手发送；按钮右上角有一个小切换键，点一下切换到「键盘输入」模式。键盘输入模式：一个多行文本框（最多 4000 字，右下角显示已输入字数）+ 一个「发送」按钮。点击发送后，先在对话区显示「正在保存原始记录…」，保存成功后显示「正在根据审核知识整理回复…」，然后用对话气泡显示 AI 的三句回复：第一句共情鼓励、第二句一个非医疗生活建议、第三句轻量正向展望，每句 10–20 个字，以句号结尾。用户自己说的话以右侧气泡显示，AI 回复以左侧气泡显示。AI 必须基于审核知识回答，禁止诊断、禁止用药、禁止判断严重程度、禁止使用「治愈/治疗/炎症/病变/确诊/用药/处方/严重/轻微」等词。
>
> 【今日记录 Tab】展示最近三个真实记录日的卡片，最新在最前，可上下滑动。每张卡片：顶部显示日期（如「8月30日 周六」）和相对称呼（今天/昨天/前天）；下面是标签行（小药丸样式，如「睡眠不佳」「容易烦躁」「关节不适」「潮热出现」「睡眠良好」「坚持运动」「三餐规律」）；中间一段两行的总结文案；再分两个小区块「推荐继续做」和「不建议做」，各一条；底部一行小字「共 N 条原始记录 · 不足的信息之后随时可以补」。没有记录的日期不要补造。
>
> 【趋势 Tab】顶部一行「数据截至 8月30日」。三个模块纵向排列：模块一「设备采集」副标题「心率·血氧」，无设备时显示「暂未检测到设备，连接后同步心率与血氧」，有数据时显示心率「72 次/分」、血氧「-」；模块二「自己说的」副标题「体重·血压·基础体温」，用三列展示最近 7 天内最新值（体重 55.3 kg、血压 118/76 mmHg、基础体温 36.7 ℃）；模块三「本周总览」副标题「只统计真实留下的记录」，三行：坚持记录 7/7 天、潮热 1 次（较上周持平）、平均睡眠 7.4 小时（较上周 -1%）。
>
> 【合成演示数据】请用以下 3 个记录日作为初始内容（其余日期留空，体现「缺失就是缺失」）：8月30日——体重55.3、血压118/76、基础体温36.7、睡眠6分、膝盖不舒服、情绪烦躁，标签「睡眠不佳/容易烦躁/关节不适」；8月29日——体重55.2、睡眠9分、心情好，标签「睡眠良好/坚持运动」；8月28日——体重55.4、睡眠7分、经期接近结束，标签「经期变化」。AI 回复示例（8月30日）：「膝盖不适加上心情烦躁，确实让人不容易。」「注意膝部保暖，睡前做轻柔放松，留意坐姿。」「坚持记录这些变化，慢慢会找到舒服的节奏。」
>
> 【医学边界】App 不是医疗诊断工具，出现疑似疾病问题时只建议持续记录并必要时线下就医。不做打卡压力，一次只给一个轻量行动方向。

## 秒哒上线步骤

1. 登录 https://www.miaoda.cn（你已登录）。
2. 新建应用，把上面整段自然语言粘贴进对话框，让秒哒生成。
3. 在编辑器里逐页核对三个 Tab 与表单/列表/数据展示组件，缺失的用拖拽补齐。
4. 配置数据：可在秒哒的数据面板录入上面合成数据（或用秒哒内置示例数据），让首页/今日记录/趋势有内容。
5. 点「发布到应用广场」，拿到 `https://xxxxx.appmiaoda.com` 链接。
6. 把该链接作为秒哒命题提交物。

> 说明：秒哒版是命题要求的「在线可访问演示」；本 GitHub 仓库（`Youjikexun-demo`，tag `shenicest-fission`）是完整工程代码与合成数据集，供评委审查实现细节。两者互补。
